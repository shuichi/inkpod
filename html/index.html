機能

彩色のために、すべてを設計。

セル彩色の現場で必要なものを、現代的なエンジンの上に。

主線保護

塗りつぶしもブラシも、主線プレーンには決して触れません。線画をフィル境界として表示したまま、色は彩色プレーンだけに置かれます。

レイヤー & プレーン

各標準レイヤーに主線と彩色を1枚ずつ保持し、背景・特効・レタッチ用ラスターを必要なだけ追加。レイヤーは合成の単位、プレーンは編集の単位です。

賢いフィル

隙間閉じ、含み塗り、閉領域フィル、塗りあふれ検出。小さな線切れや色トレースがあっても、高速かつ安全に塗れます。

描画ツール

鉛筆、ブラシ、エアブラシ、直線・曲線・図形・折れ線。筆圧、決定的な手ブレ補正、自動消去に対応。

選択範囲

矩形・楕円・投げ縄・折れ線・トレース・色指定。追加・削除・交差、拡張・縮小も自在に。

ライトテーブル

前後のセルを基準フレームで整列し、半透明で重ねて参照。距離に応じた不透明度ステップにも対応。

連番 & モーションチェック

Sequenceでセルを自然順に確認し、30 / 24 / 12 fps などでループ再生。各セルは独立して安全に保存します。

フィルター

色調カーブ、レベル補正、色相・彩度、カラーバランス。プレビュー後に一回のUndo単位として適用。

バッチ処理

色置換、彩色プレーンへ送る、マスキング、消去を連番セルへ一括適用。実行前検証と一件ごとの原子的な出力で安全に。

履歴 & 復元

元に戻す／やり直し、複数段階ジャンプ、自動保存とクラッシュ復元。分岐した履歴も失われません。

カラーチャート

色と名前を表で管理し、ページ・検索・ロックに対応。セルから一意色を抽出して自動生成も。

撮影フレーム

中心・寸法・角度を持つ撮影フレームを非破壊で保持。Canvas 上のハンドルと数値入力で編集できます。

保存選択マスク

現在の選択を名前付きで文書に保存。複数マスクの置換・加算・減算、改名、削除、Undo／Redoに対応。

コンセプト

レイヤーの中に、プレーンがある。

inkpod の文書は「セル → 標準レイヤー → プレーン」の階層で構成されます。各レイヤーは主線と彩色を1枚ずつ必須とし、ラスターを必要なだけ追加できます。現在の選択と名前付き保存マスクはレイヤー外で文書が所有します。

主線保護は、構造で保証。

すべての標準レイヤーで、主線プレーンをフィル境界として表示しながら、塗りつぶしと彩色ブラシは彩色プレーンへ書き込みます。線画を壊す事故は、運用ではなく構造で防ぎます。

テクノロジー

速さも、未来も、制作の過程も。

長く育てられる設計、OS 標準の速さ、すべてを残す編集履歴。inkpod の強さは、その中身にあります。

10年先も、AIと育て続けられる

コアは特定の OS や CPU に依存しない設計。部品ごとの自動テストと AI 向け開発ガイドを備え、AI だけでも変更を検証しながら安全にアップデートできます。GUI は外部ライブラリに頼らず、OS の標準機能を直接活用。現在の Windows から、macOS、Android、iOS、Web へ展開予定です。

OS-independent core · tests · AI guide

ゼロからつくったから、驚くほど速い

inkpod は、現代の 64 ビット OS が持つ性能を最大限に引き出すため、彩色アプリとしてゼロから設計・開発されています。Windows 版では Win32、Direct3D 11、Direct2D という、長年にわたり維持されてきた OS 標準技術を採用。将来の macOS 版でも、Apple 公式の SwiftUI を中心としたネイティブ技術を使用する予定です。

64-bit native · Win32 · D3D11 · Direct2D

完成した絵だけでなく、そこへ至る過程も残す

通常保存は、編集履歴を保つ .inkpod と同じstemのPNG／TIFF／TGA／BMPを一組で管理します。.inkpod のジャーナルはファイルを開き直したあともUndo／Redoと分岐履歴を復元し、ラスター相手は一般ツールで確認できる合成画像を保ちます。

native + raster pair · persistent Undo / Redo

スパースタイル & キャッシュ

大画像はタイル単位で遅延割当・copy-on-write。変更されたタイルだけを再合成し、パン／ズームはキャッシュを再利用します。

sparse tiles · COW · revision-max cache
