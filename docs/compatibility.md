The 2026-07-23 GUI vertical-slice audit treats production menu/dialog/toolbar/
Canvas routing through the Windows adapter, C ABI, Core, and result display as
part of completion for user-invoked requirements. ABI calls made only by the
application smoke test do not satisfy that condition. A requirement remains
`In progress` when any user-visible operation grouped under its ID is not
exposed; completed Core/ABI subsets remain documented above. Internal build,
ABI, and renderer contracts do not need artificial GUI commands.

M5 was re-verified before M6 edits with all five named acceptance tests passing
5/5. M6 is `Verified`: all five acceptance scenarios, the completed native
filter/effect/adjustment vertical slices, dust removal, and worker progress/cancel
are covered by Rust and integrated C11/C++20/D2D automation. Debug and Release
strict builds passed; final Debug CTest passed 3/3. The newly linked unsigned
Release EXE was blocked by local Application Control before its two executable
tests could start, while its asset test passed. M7 remains `Not started` and no
batch behavior is claimed.
