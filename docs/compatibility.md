## Procedure-history redesign traceability

M0 fixes the successor contract and route ownership, M1 implements one
canonical executor for main-line color, palette replacement, and one raster
stroke, M2 adds the closed append-only runtime journal and cache-free replay for
exactly that canonical slice, and M3 moves session editor defaults/state into
Rust Core with an additive ABI v2 presentation bridge. M3 implements the
canonical target EDIT DTO in memory; M9 persists it in v9. The M4 implementation slice introduces a distinct
Genesis Cell ID, typed immutable `SolidWhite`/asset base surfaces, and a
Core-owned content-addressed canonical asset registry with deduplication,
bounded ingestion, and semantic retention roots. The M4 milestone is
final-verified at its Core/runtime, existing ABI-v2 ingestion, and Windows
connection boundaries. M5 adds the ABI-v3 value/ID control plane and closed
typed mutation queue. M6 then routes every production document mutation through
a stable-ID canonical invocation and removes the arbitrary-callable queue
bridge. M8 completes the current-only procedure-authoritative native cutover,
including journal/asset/editor persistence and Windows save/reopen behavior.
